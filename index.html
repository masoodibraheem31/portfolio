I started in 2015 in Srinagar, building ASP.NET MVC sites and writing a foreach loop for everything. Then I found LINQ, and it changed how I think: describe what you want, and let the code read like the intent.

Most of my career since has been in healthcare. I architected Invaryant, an HL7-based Electronic Health Record platform for a US client, and later connected three separate healthcare portals to it while keeping every flow HIPAA-compliant. That work taught me to care about the boring parts: role-based access, data contracts, audit trails, and what happens on the 100,000th record.

In 2026 I moved into leading a team, right as AI started writing a large share of our code. AI-generated code tends to look clean, and clean code is no longer proof of correct code. So I wrote our AI-assisted development policy, built a curriculum around verification, and shipped a full application with Claude Code to show the team where review agents earn their keep. They caught six real bugs that a human reviewer would have waved through.

Outside the codebase, I run a commercial ultra-high-density apple orchard in Pampore. Farming and software reward the same habit: measure first, then change one thing at a time.
